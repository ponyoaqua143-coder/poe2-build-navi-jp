# Operating Rules（このリポジトリでの実務ルール）

- 人間承認が必要な操作は実行しない: ドメイン購入、有料SaaS契約、広告費支出、
  AdSense/アフィリエイト等の外部アカウント開設、SNSアカウントでの実際の投稿、
  本番データ削除、プライバシーポリシー等法的文書の最終確定。
- 上記の判断・実行主体（Search Console登録やGA導入も含む）は人間が行う。AIは草案・実装まで担当する。
- コンテンツの断定表現は避け、根拠と最終更新日を明記する。
- 各記事は「結論→理由→具体的方法→比較→注意点→次の行動」の構成を基本とする。
- Grinding Gear Gamesとの非公式・無関係である旨をフッター等に必ず明記する。
- 大きな変更（サイト構造変更、新規事業立ち上げ等）はdecisions.mdに記録してから実行する。
